# 제3본부 — 미래채움 주간업무보고 본부 (수정 구축 명세)

## 목표
기존 'SW 미래체험 본부'와 '정부지원사업 본부'는 그대로 유지하고, '미래채움 주간업무보고 본부'를 독립적인 제3본부로 운영한다.
**초안 작성 주체는 직원 3명이 아니라 AI**이다. AI는 **미래채움 카카오톡 단체방, 회사 업무 이메일 중 미래채움 관련 내용, 2027년도 사업계획서, 2026년도 사업 결과보고서**를 종합적으로 참고하여 사업 전체의 주간업무보고 초안을 먼저 만든다. 직원 3명은 **하나의 공동 문서를 직접 수정**하고 각자 이름 옆의 '검토' 버튼을 눌러 '완료'로 변경한다. 3명 모두 '완료'이면 상급자가 최종 자료임을 확인할 수 있도록 상태를 표시한다.
용역사의 교육현황 실적은 자동 수집·업로드 대상에서 제외하고, 관리자가 수동 입력한다.

## 수집 대상과 출처 통제
- 카카오톡: 지정된 미래채움 업무 단체대화방만. 수집 방식은 별도 검증. 개인 카톡방·기타 업무방은 수집하지 않는다.
- 이메일: 미래채움 관련 메일만 필터링. 단순 키워드만으로 확정하지 않고 담당자·사업 키워드·문맥·사용자 분류와 예외 목록을 조합한다.
- 2027년도 사업계획서: 연간 사업목표·일정·세부 과업·성과지표·후속 추진과제를 파악하는 기준 자료로 사용한다. 문서가 '계획'임을 유지하고, 계획만으로 실제 완료했다고 판단하지 않는다.
- 2026년도 사업 결과보고서: 이전 수행 결과·진행 경과·미완료 후속 과제·반복 업무를 이해하는 배경 자료로 사용한다. 결과보고서가 다루지 않는 미래의 사실은 추정으로 표시한다.
- 원문 출처 ID·날짜·문서 링크 등 근거를 보존하고, 중복된 업무는 하나로 합친다.
- 실제 회사 메일 자동 수집이나 카카오톡 자동 수집은 시스템의 허용 기능, 기관 승인 및 개인정보 보호 검증이 완료되기 전 활성화하지 않는다.
- 공식 카카오톡 일반 단체대화방의 직접 조회 API가 제공된다고 가정하지 않는다. 연동이 불가능하면 사용자가 내보낸 대화 TXT 등의 파일을 지정 영역에 업로드하는 대안을 적용한다.
- 이메일도 IMAP 실제 서버 주소·포트·권한 승인 전 자동 수집하지 않는다.

## 주간 업무 흐름
1. 지정 기간의 미래채움 단체 카카오톡 대화와 미래채움 관련 업무 이메일 수집/입력 및 2027년도 사업계획서, 2026년도 사업 결과보고서 참조
2. 내부 보안 필터에서 개인정보·비공개 정보 탐지·제거·차단 및 외부 반출 허용 여부 검사
3. AI가 자료 4종을 교차분석하여 사업 전체의 '금주 추진실적 / 차주 추진계획 / 주요 현안' 초안을 생성한다. **금주 실적은 실행이 확인된 사실만**, **차주 계획은 확정 일정과 AI가 제안한 필요 업무를 모두 포함**하되, '확정/예정/AI 제안' 표시로 구분한다. 사업계획서·결과보고서의 목표와 과거 경과를 바탕으로 빠진 준비사항, 후속 처리, 행정 보고, 향후 일정 및 선행 작업까지 제안한다.
4. 교육현황 실적은 관리자가 직접 입력하고 초안에 반영
5. 직원 3명은 본부의 **같은 보고서 전체**를 열람·수정할 수 있다. 각 직원 이름 옆의 기본 버튼은 **'검토'**이며, 각자 내용을 확인하고 누르면 **'완료'**로 변경하고 사용자/시각/보고서 버전을 기록한다.
6. **3명 모두 '완료'(3/3)**이면 상급자 화면에 '전원 검토 완료 · 최종 보고자료' 상태를 보여준다. 미완료자가 있으면 '검토 중'을 표시한다. **검토 완료 후 본문이 다시 수정되면 이전 완료 표시는 무효화되어 해당 사용자 재검토가 필요하다.** 상급자는 필요시 최종 승인/확정한다.
7. 기관의 실제 주간업무보고서 서식에 맞춰 파일 출력

## 역할 및 공유
- 관리자: 자료 수집 범위/보고 주차 설정, 교육현황 수동 입력, 전체 수정·확정·출력
- 직원 3명: 같은 초안의 **전체 본문을 공동으로 열람·수정**하고 각자의 이름 옆 '검토' → '완료' 처리. 이력, 충돌 방지, 수정 후 재검토 정책 적용
- 직원에게는 주간업무보고 본부만 노출하고 서버 API·DB 수준에서도 다른 두 본부에 대한 접근을 차단한다.
- 동시 수정 충돌을 방지하기 위해 영역별 편집 잠금 또는 버전 충돌 감지 사용, 수정 기록과 이전 버전 유지
- 실제 직원명·담당 영역은 미확정이며 임의 지정하지 않는다.

## 화면 구성
- 상단: 보고 주차, 초안 생성 시각, 출처 처리 현황, 교육현황 수동 입력 상태
- 중앙: AI가 만든 사업 전체 보고서 초안(금주 실적/차주 계획/주요 현안)을 **모든 직원이 직접 편집 가능**, 변경 시 자동 저장/수정 이력 기록
- 차주 계획 AI 제안은 확정 일정과 시각적으로 구분하고, 직원이 채택·수정·삭제할 수 있게 한다.
- 오른쪽 또는 하단: **직원 3명 이름과 각자 '검토' 버튼**. 누르면 '완료'로 변경되며 완료자/시간/문서 버전을 기록. 상급자에게 3/3 최종 확인 상태를 제공한다.
- 각 항목: 근거 출처(카톡/메일), 발신 일자, 출처 열람 권한 있는 사용자만 열 수 있는 근거 연결, 확인 필요 표시
- 하단: 변경 이력, 관리자 최종 승인, 파일 출력

## 보안
- 회사 메일·카톡 원문을 외부 AI 서비스에 직접 전송하지 않고 승인된 내부 처리 구간에서 필터링한다.
- 개인 식별정보 및 외부 반출 금지 자료를 제거하더라도 재식별·업무 기밀 위험 검토가 필요하다. 불확실하면 전송 보류.
- 원문, 직원 보고자료, 인증 토큰을 공개 GitHub나 브라우저 localStorage에 저장하지 않는다.
- 원본 자료 열람은 최소권한. 접근·분석·수정·다운로드에 감사 로그를 남긴다.
- 이메일 발송이나 카카오톡 메시지 전송·삭제 기능은 이번 범위에서 제외한다.

## 실제 HWP 기준 양식 (2026-11-11 업로드 파일 확인)

참조 문서: `1111-혁신기술교육센터 주간업무보고.hwp`의 **「소프트웨어(SW) 미래채움사업」 행만** 이용한다. ICT이노베이션스퀘어, 블록체인 등 다른 사업 부분은 분석·출력 대상에서 제외한다.

- 문서 상단은 보고 기간 2열: **주간실적(2026. 11. 9.~11. 13.) / 주간계획(2026. 11. 16.~11. 20.)**. 새 주차마다 날짜만 갱신하고 기존 양식·문체를 유지한다.
- **주간실적 상단 수동 교육현황 표:** ‘찾아가는 AI·SW교육 및 센터 내 교육 운영 현황’의 교육완료/교육진행 구분, 기관(개), 신청인원(명). 목표 대비 달성률도 근거가 있는 경우에만 입력. 예시 데이터는 실적값을 그대로 재사용하지 않는다.
- **주간계획 상단 수동 교육예정 표:** ‘찾아가는 AI·SW교육 및 센터 내 교육 운영 계획’의 교육예정 기간, 기관(개), 신청인원(명).
- **사업 업무 본문:** 실적/계획 각각 항목별 `- ...` 서술 형식(기존 HWP 문체와 날짜 표기 유지); 수행계획서, 강사 상호 보수교육, 강사연구회, 교안 검수·역량평가 문항 개발, 강사 수당 지급, 협약 변경, 교육페스티벌 결과보고, 강사 협동조합 지원사업 등 미래채움 사업 업무만 다룬다.
- **교육현황 자동 수집 금지:** 용역사 데이터는 사용자가 직접 입력. 입력된 수치·기간·단위를 원문 그대로 유지하고 합계 검증 가능.
- **AI 초안 생성:** 미래채움 카톡방/관련 이메일에서 확인된 내용만 근거로 금주 실적과 차주 계획에 분류. 원문 출처·날짜 기록, 중복 제거, 사실/계획 구분, 수치·금액 검증; 근거 없는 새 일정·성과 추정 금지.
- **검토 방식:** 직원 3명은 동일한 AI 초안을 각자 담당 업무 기준으로 검토/수정/확인. 최종 승인 및 HWP/HWPX 출력은 관리자.
- 대상 HWP의 ‘주간실적’ 및 ‘주간계획’은 서로 다른 기준 기간이므로, 같은 메일/대화라도 업무 실적과 미래 예정 내용을 구분해야 한다. 원문에서 날짜가 불명확하면 ‘확인 필요’로 두고 임의 배치하지 않는다.
- 실제 HWP 편집/출력은 파일 처리 기능이 구현된 후 서식을 검증한다. 현재 이 문서는 구현 명세이며 최종 자동생성 동작을 뜻하지 않는다.


## 2026-11-14 추가 확정 요구사항
- 보고서 자동작성 근거는 4종 자료 전체를 함께 분석한다. *수집 자료의 허가·접근·개인정보 필터링 선행*. 2027년도 사업계획서와 2026년도 결과보고서는 실제 파일이 확보되어야 활용 가능.
- 계획 작성에서 단순 일정 발췌를 넘어 필요한 다음 주 업무를 적극 제안한다. 제안 근거/우선순위/확정 여부를 표시한다.
- 직원 3명이 하나의 보고서를 직접 수정하며, 저장된 문서 버전 기준으로 각각 '검토'를 누를 수 있다. 누르면 '완료'로 표시.
- **3명 전원 완료 = 상급자에게 '최종 제출용 검토 완료' 표시**, 필요시 상급자 확정 절차 별도. 수정 후 이전 검토 결과는 무효.
- 교육현황 실적·계획 표는 사용자 수동 입력 유지.
